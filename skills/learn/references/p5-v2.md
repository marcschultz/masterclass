# p5.js 2.x – things to get right

Read this when the project uses p5.js 2.x (e.g. `p5@2.x` in index.html,
or "p5": "^2..." in package.json). Only write code in 2.x style.
Many online tutorials and examples are still written for 1.x – when the user
pastes code from the web, check it against this file and explain any differences.

## Loading assets: async setup() + await (no preload)
```js
let img, font;

async function setup() {
  createCanvas(400, 400);
  img = await loadImage('bricks.jpg');
  font = await loadFont('myFont.otf');
}
```
- `preload()` does not exist in 2.x (unless the preload.js compatibility add-on is loaded).
- Load functions return Promises. Explain `async`/`await` to beginners the first time.
- `loadTable(filename, [separator], [header], ...)` – second parameter is now the separator.
- `loadBytes()` returns the `Uint8Array` directly (no `.data`).

## Shapes
- Smooth curves: `splineVertex()` instead of `curveVertex()`.
  With `endShape(CLOSE)` the shape closes smoothly; extra control points are not needed.
- Renamed: `curve()` → `spline()`, `curvePoint()` → `splinePoint()`,
  `curveTangent()` → `splineTangent()`, `curveTightness(t)` → `splineProperty('tightness', t)`.
- Bézier: each `bezierVertex(x, y)` is ONE point. Start with an anchor vertex,
  then every curve segment needs 3 `bezierVertex()` calls (with the default `bezierOrder(3)`).
  ```js
  beginShape();
  vertex(30, 20);          // anchor
  bezierVertex(80, 0);     // control 1
  bezierVertex(80, 75);    // control 2
  bezierVertex(30, 75);    // end point
  endShape();
  ```
- Quadratic curves: `bezierOrder(2)` + `bezierVertex(x, y)` calls (no `quadraticVertex()`).
- `bezierDetail()` is removed; `curveDetail()` covers both.
- 3D geometry: only `buildGeometry()` (no `beginGeometry()` / `endGeometry()`).

## Vectors
Always give the dimensions: `createVector(0, 0)` for 2D, `createVector(0, 0, 0)` for 3D.
Never write `createVector()` without arguments.

## Input
- Mouse button is an object with booleans (several buttons at once possible):
  `if (mouseButton.left) { ... }`, `if (mouseButton.right) { ... }`
- Arrow keys: `if (code === UP_ARROW) { ... }` (not `keyCode === UP_ARROW`).
- Named keys: `key === 'Enter'`, physical keys: `code === 'KeyA'`.
- `keyIsDown(UP_ARROW)` works as before.
- Touch: no `touchStarted()` / `touchMoved()` / `touchEnded()`. Mouse handlers
  (`mousePressed()` etc.) handle touch too; the `touches` array lists active pointers.

## Text
- `textWidth()` measures tightly (without leading/trailing spaces).
  Use `fontWidth()` if spaces should count.
- `textToPoints()` has no font-size parameter – call `textSize()` first:
  ```js
  textSize(35);
  let pts = font.textToPoints('p5*js', 6, 60, { sampleFactor: 0.5 });
  ```
- 2.x supports variable fonts and `textToContours()`.

## Color
- New color modes such as OKLCH and OKLAB.
- Since 2.3.1, the wide-gamut color space formerly called HDR is called P3.

## Shaders
- `shader()` always applies to fills, also with lights. Limit its scope with
  `push()` / `pop()` or `resetShader()`.
- `strokeShader()` and `imageShader()` set separate shaders for strokes and images.
- p5.strands lets you write shaders in JavaScript (advanced users only).

## Removed data helpers
Use plain JavaScript instead of `append()`, `arrayCopy()`, `concat()`, `reverse()`,
`shorten()`, `sort()`, `splice()`, `subset()`, `createStringDict()`, `createNumberDict()`:
`arr.push(x)`, `[...arr]`, `arr.concat(b)`, `arr.reverse()`, `arr.pop()`,
`arr.sort()`, `arr.splice()`, `arr.slice()`, objects and `Map`.

## Libraries
- Use the new p5.sound.js (works with 1.x and 2.x); the old p5.sound does not work with 2.x.
- p5.brush requires 2.x (and WEBGL).
- Before suggesting any other add-on library, tell the user to check it supports 2.x.
