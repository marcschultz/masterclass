# p5.js 1.x – things to get right

Read this when the project uses p5.js 1.x (e.g. `p5@1.11.x` in index.html).
Only write code in 1.x style. Do not use any 2.x-only API (see p5-v2.md).

## Support status
- 1.x receives no further feature updates since the end of March 2026.
- Since August 2026, 2.x is the default in the p5.js Editor.
- 1.x still works. Don't push the user to upgrade; mention it once if relevant.

## Loading assets: use preload()
```js
let img, font;

function preload() {
  img = loadImage('bricks.jpg');
  font = loadFont('myFont.otf');
}

function setup() {
  createCanvas(400, 400);
  image(img, 0, 0);
}
```
Never use `async function setup()` or `await` with load functions in 1.x.

## Shapes
- Smooth curves: `curveVertex()`, `curve()`, `curvePoint()`, `curveTangent()`,
  `curveTightness()`.
- Bézier: one `bezierVertex(x2, y2, x3, y3, x4, y4)` call = one full curve segment
  (three points per call).
- Quadratic curves: `quadraticVertex(cx, cy, x, y)`.
- Detail: `curveDetail()` and `bezierDetail()` are separate.
- 3D geometry: `beginGeometry()` / `endGeometry()` or `buildGeometry()`.
- `endContour()` behaves like `endContour(CLOSE)`.

## Vectors
`createVector()` with no arguments returns a 3D zero vector (0, 0, 0).

## Input
- Mouse button: `if (mouseButton === LEFT) { ... }`
- Arrow keys: `if (keyCode === UP_ARROW) { ... }`
- Touch: `touchStarted()`, `touchMoved()`, `touchEnded()` exist.

## Text
- `textWidth()` includes leading and trailing spaces.
- `font.textToPoints(str, x, y, fontSize, options)` takes the font size as a parameter.

## Data helpers (exist in 1.x, removed in 2.x)
`append()`, `arrayCopy()`, `concat()`, `reverse()`, `shorten()`, `sort()`,
`splice()`, `subset()`, `createStringDict()`, `createNumberDict()`.
Prefer plain JavaScript (arrays, objects, Map) anyway – it works in both versions
and makes later upgrades easier. Teach that as good practice.
